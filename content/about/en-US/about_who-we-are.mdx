# maioli.dev

**maioli.dev** grew from my desire to have a space of my own where I could present my work in a way that a résumé or professional profile rarely can.

More than a collection of repository links, this website brings together projects that represent different moments in my journey as a developer.

## Why create my own portfolio?

A repository shows the code. A résumé summarizes experience. Neither one, however, tells the story behind a project particularly well.

That is exactly the other side I want to show here.

Each project has its own context: the problem that led me to build it, the decisions I had to make, what I learned during the process, and, most importantly, how that work represents the way I develop software.

## Projects beyond the code

Some projects began as experiments. Others were created to solve specific problems. Some evolved far beyond their original idea.

For that reason, the articles in this portfolio avoid going too deeply into technical details.

Anyone interested in the architecture, code, tools, or implementation details can follow the link to each project's corresponding GitHub repository.

Here, the goal is to tell **the story behind the code**.

## A project that keeps evolving

maioli.dev itself is part of that story.

It will continue to evolve as new projects are developed, new experience is gained, and new ideas emerge.

That is why I see this website not only as my portfolio, but also as a project in constant development.
