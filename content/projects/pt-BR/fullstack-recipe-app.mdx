# Fullstack Recipe App

Este projeto é um aplicativo mobile que permite aos usuários explorar e criar suas próprias receitas, suportando múltiplos temas visuais e um backend robusto em Node.js com banco de dados PostgreSQL.

## Funcionalidades
- Temas customizados inspirados em diversas paletas.
- Busca, filtragem e categorias.
- Autenticação e sistema de favoritos.
- API RESTful completa.
