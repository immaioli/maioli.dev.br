# Full-Stack Recipe App

O **Full-Stack Recipe App** é um aplicativo criado para explorar uma experiência completa de produto no ambiente mobile.

A proposta é simples: permitir que uma pessoa encontre receitas, explore diferentes categorias e mantenha seus pratos favoritos disponíveis em sua conta.

## Da descoberta ao prato favorito

O aplicativo permite navegar por diferentes receitas e pesquisar pratos de acordo com o interesse do usuário.

Quando uma receita chama atenção, ela pode ser adicionada aos favoritos para ser encontrada novamente mais tarde.

Embora seja uma funcionalidade aparentemente simples, ela transforma a aplicação: favoritos precisam pertencer à pessoa correta e continuar disponíveis mesmo depois que o aplicativo é fechado.

Isso significa que existe um sistema completo trabalhando por trás da interface.

## Uma experiência conectada

As informações das receitas vêm de um serviço externo, enquanto os dados pessoais do usuário precisam ser administrados pela própria aplicação.

O desafio foi fazer essas diferentes partes parecerem uma única experiência.

Para quem utiliza o aplicativo, não deveria importar de onde uma informação veio ou onde determinado dado foi armazenado.

Tudo precisa simplesmente funcionar como um único produto.

## O que este projeto representa

Este projeto foi uma oportunidade de trabalhar o desenvolvimento Full-Stack fora do navegador tradicional.

Ele conecta interface mobile, autenticação, serviços externos, backend e persistência de dados dentro da mesma experiência.

Mais do que uma aplicação de receitas, ele representa a capacidade de acompanhar uma funcionalidade desde aquilo que o usuário toca na tela até os serviços responsáveis por fazê-la funcionar.
