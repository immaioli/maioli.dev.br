# Ecoleta

O **Ecoleta** é uma aplicação criada para aproximar pessoas que precisam descartar determinados materiais dos locais preparados para recebê-los.

A ideia parte de um problema cotidiano: muitas pessoas sabem que determinados resíduos não deveriam ser descartados no lixo comum, mas não sabem onde levá-los.

## Conectando pessoas e pontos de coleta

A plataforma trabalha com dois lados do problema.

Estabelecimentos podem cadastrar seus pontos de coleta e informar quais tipos de materiais recebem.

Pessoas interessadas em realizar um descarte podem utilizar o aplicativo para localizar esses pontos e descobrir quais estão mais próximos.

O mapa torna essa descoberta mais natural, transformando uma lista de endereços em uma visão geográfica dos locais disponíveis.

## Web e mobile trabalhando juntos

O projeto também foi importante por envolver diferentes formas de interação com o mesmo sistema.

O ambiente web é utilizado para cadastrar informações, enquanto a experiência mobile é voltada principalmente para quem procura pontos de coleta.

As duas aplicações trabalham com os mesmos dados, mas possuem necessidades diferentes.

## O que este projeto representa

O Ecoleta marcou uma etapa importante da minha evolução no ecossistema JavaScript/TypeScript porque reuniu **frontend web, aplicativo mobile e backend** dentro de uma mesma solução.

Apesar de ser um projeto desenvolvido originalmente em um ambiente de aprendizado, ele continua sendo relevante por mostrar uma das primeiras experiências em que trabalhei diferentes partes de um produto como componentes de um único sistema.
