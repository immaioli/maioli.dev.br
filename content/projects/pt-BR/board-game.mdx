# Jogo de Tabuleiro Interativo

Construir jogos de navegador puros sempre foi um desafio fascinante para mim. Este projeto visa entregar uma experiência de tabuleiro cooperativa usando comunicação via sockets de baixa latência.

## Arquitetura
Utilizamos a Canvas API do HTML5 para renderização a 60FPS dos tokens no tabuleiro e Node.js com Socket.io no backend para sincronizar as jogadas entre múltiplos clientes espalhados pelo mundo.
