# Fullstack Recipe App

This project is a mobile application that allows users to explore and create their own recipes, featuring multiple visual themes and a robust Node.js backend with PostgreSQL database.

## Features
- Custom themes inspired by various color palettes.
- Search, filtering and categories.
- Authentication and favorites system.
- Full RESTful API.
