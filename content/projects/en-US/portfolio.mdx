# maioli.dev.br Portfolio

This is the repository that brings this showcase to life. The site was created from scratch using Next.js 16 and the App Router.

## Why Next.js?
The ability to manage Internationalization natively and take advantage of Server Components allowed me to deliver a very fast static application (SSG) with interactive Themes content.
Content validation with `gray-matter` and `zod` ensures that my pipeline fails locally if I write any article with missing information.
