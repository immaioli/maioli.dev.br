# Interactive Board Game

Building pure browser games has always been a fascinating challenge for me. This project aims to deliver a cooperative board experience using low latency socket communication.

## Architecture
We use the HTML5 Canvas API for 60FPS rendering of tokens on the board and Node.js with Socket.io on the backend to synchronize plays between multiple clients spread across the world.
