# Ecoleta

The **Ecoleta** project was created to connect people who need to dispose of certain materials with places prepared to receive them.

The idea starts with an everyday problem: many people know that some types of waste should not go into regular trash, but they do not know where to take them.

## Connecting people and collection points

The platform works with both sides of the problem.

Organizations can register collection points and specify which types of materials they accept.

People who need to dispose of something can use the application to find these locations and discover which ones are nearby.

The map makes that discovery more natural, turning a list of addresses into a geographic view of the available collection points.

## Web and mobile working together

The project was also important because it involved different ways of interacting with the same system.

The web environment is used to register information, while the mobile experience is mainly focused on people looking for collection points.

Both applications work with the same data, but they have different needs.

## What this project represents

Ecoleta marked an important step in my evolution within the JavaScript/TypeScript ecosystem because it brought together **web frontend, mobile application, and backend** in the same solution.

Although it was originally developed in a learning environment, it remains relevant because it shows one of my first experiences working with different parts of a product as components of a single system.
