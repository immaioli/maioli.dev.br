# maioli.dev.br Portfolio

The **maioli.dev.br** project was born from the idea of having my own space to present my work in a way that a résumé or a professional profile usually cannot.

More than a collection of links to repositories, this site brings together projects that represent different moments in my journey as a software developer.

## Why create my own portfolio?

A repository shows the code. A résumé summarizes experience. But neither of them tells the full story behind a project very well.

That is exactly what I want to show here.

Each project has its own context: the problem that led me to build it, the decisions I had to make, what I learned along the way, and most importantly, how that work represents the way I approach software development.

## Projects beyond the code

Some projects started as experiments. Others were created to solve specific problems. And some evolved far beyond the original idea.

That is why the articles in this portfolio avoid going too deep into technical details.

For anyone interested in architecture, code, tools, or implementation details, each project includes a link to its respective GitHub repository.

Here, the goal is to tell **the story behind the code**.

## A project that keeps evolving

The maioli.dev.br site itself is part of that story.

It will continue to evolve as new projects are created, new experiences are added, and new ideas emerge.

For that reason, I see this site not only as my portfolio, but also as a project that is always under construction.
