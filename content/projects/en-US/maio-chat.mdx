# mAIo - Personal Assistant

Platform under development. Soon, this space will be dedicated to sharing projects, practical studies, and documentation on new technologies.

This assistant is powered by the **Vercel AI SDK** with Retrieval-Augmented Generation (RAG) to provide fast, relevant, and context-aware responses based on my professional experience.

## Key Features

- **Context-Aware Responses:** Capable of retrieving up-to-date data about my skills, projects, and work history.
- **Microservices Architecture:** Ensures high availability. If the primary LLM provider fails, a resilient **Classifier API** takes over.
- **Blazing Fast UI:** Built with Next.js App Router for optimal rendering performance.
