# Full-Stack Recipe App

**Full-Stack Recipe App** es una aplicación creada para explorar una experiencia de producto completa en el entorno móvil.

La propuesta es simple: permitir que una persona descubra recetas, explore diferentes categorías y mantenga sus platos favoritos disponibles en su cuenta.

## Del descubrimiento al plato favorito

La aplicación permite navegar por distintas recetas y buscar platos de acuerdo con el interés del usuario.

Cuando una receta llama la atención, puede guardarse como favorita para encontrarla nuevamente más adelante.

Aunque parezca una funcionalidad simple, cambia por completo la aplicación: los favoritos deben pertenecer a la persona correcta y seguir disponibles incluso después de cerrar la app.

Eso significa que existe un sistema completo trabajando detrás de la interfaz.

## Una experiencia conectada

La información de las recetas proviene de un servicio externo, mientras que los datos personales del usuario deben ser administrados por la propia aplicación.

El desafío fue hacer que esas distintas partes se sintieran como una sola experiencia.

Para quien utiliza la aplicación, no debería importar de dónde vino una información o dónde se almacenó determinado dato.

Todo debería simplemente funcionar como un único producto.

## Lo que representa este proyecto

Este proyecto fue una oportunidad para trabajar el desarrollo Full-Stack fuera del navegador tradicional.

Conecta una interfaz móvil, autenticación, servicios externos, backend y persistencia de datos dentro de una misma experiencia.

Más que una aplicación de recetas, representa la capacidad de seguir una funcionalidad desde lo que el usuario toca en la pantalla hasta los servicios responsables de hacerla funcionar.
