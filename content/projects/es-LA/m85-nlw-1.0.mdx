# Ecoleta

**Ecoleta** es una aplicación creada para acercar a las personas que necesitan desechar determinados materiales con los lugares preparados para recibirlos.

La idea parte de un problema cotidiano: muchas personas saben que ciertos residuos no deberían tirarse junto con la basura común, pero no saben dónde llevarlos.

## Conectando personas y puntos de recolección

La plataforma trabaja con los dos lados del problema.

Los establecimientos pueden registrar sus puntos de recolección e informar qué tipos de materiales reciben.

Las personas que necesitan realizar un descarte pueden utilizar la aplicación para encontrar esos puntos y descubrir cuáles están más cerca.

El mapa hace que ese descubrimiento sea más natural, transformando una lista de direcciones en una vista geográfica de los lugares disponibles.

## Web y móvil trabajando juntos

El proyecto también fue importante porque involucró diferentes formas de interactuar con el mismo sistema.

El entorno web se utiliza para registrar información, mientras que la experiencia móvil está enfocada principalmente en las personas que buscan puntos de recolección.

Ambas aplicaciones trabajan con los mismos datos, pero tienen necesidades diferentes.

## Lo que representa este proyecto

Ecoleta marcó una etapa importante de mi evolución dentro del ecosistema JavaScript/TypeScript porque reunió **frontend web, aplicación móvil y backend** dentro de una misma solución.

Aunque originalmente fue desarrollado en un contexto de aprendizaje, sigue siendo relevante porque muestra una de mis primeras experiencias trabajando distintas partes de un producto como componentes de un único sistema.
